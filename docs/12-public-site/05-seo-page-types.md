# SEO Page Types

**Status:** Draft (stub)
**Owner:** Content / SEO Editor

---

## Page-type strategy

| Type | Goal | Priority |
|---|---|---|
| Group sales pages | High-intent group queries | P0 |
| Programmatic landings | Country × topic | P0 |
| City pages | Long-tail city + product | P1 |
| Height pages | Specific-need queries | P1 |
| Problem/objection pages | Objection-driven | P1 |
| PDP | Product-name searches | P1 |
| Category PLP | Wide commercial queries | P2 |
| Guides | Top-of-funnel | P2 |
| FAQ standalone | Long-tail Q queries | P3 |

## Required elements per page type

### Programmatic landing
- ≥ 600 words native Arabic copy
- 3–5 SKU comparison table
- FAQ with FAQPage schema
- City-specific delivery copy
- 3 internal guide links + 5 product links
- 1 unique hero image
- BreadcrumbList + WebPage schema

### Group sales page
- Group hero
- Who it's for / Best for / Not best for
- Top 3 recommended SKUs
- Diff-highlighted comparison
- Quick selector (mini-Finder)
- Trust block
- FAQ
- WhatsApp + direct buy CTAs
- 400–600 word SEO copy
- ItemList + FAQPage schema

### City pages
- City-specific hero
- City-specific delivery copy + ETA
- Top SKUs available in city
- Local payment methods + WhatsApp number

### Height pages
- "Best 4m ladder" type framing
- SKUs at that height
- Reach calculator embedded

### Problem pages
- "I need a ladder that fits in my car"
- Comparison of fits-in-car SKUs
- Linked to Ladder Finder + Fit My Car tool

## Internal link graph

- Each guide → 5 products + 3 guides
- Each landing → 3 guides + 5 products
- Each group → all SKUs in group + 3 guides
- Each PDP → group + 3 related + 1 guide
