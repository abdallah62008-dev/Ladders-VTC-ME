## How to use this tracker

- Each row is a **decision**, **open question**, or **Phase 1 blocker**.
- Rows with multiple closely related sub-TODOs are consolidated into one decision.
- "Recommended answer" is a sensible default informed by Master Plan v4 and prior conversations — **the decision is not made until you mark Status as `🟢 Answered`**.
- Update Status as decisions are made. Add Notes when answering.
- The tracker is **never deleted**; superseded entries get Status `⚪ Deferred` with a note pointing to the replacement.

## How decisions update this tracker

When you answer a decision:

1. Change its **Status** to `🟢 Answered`.
2. Move the answer text from **Recommended** to a new line in **Notes** prefixed with `ANSWER (YYYY-MM-DD): ...`.
3. Add a `### Changed` entry to `/docs/CHANGELOG.md` referencing the decision ID.
4. If the answer affects an ADR, update the ADR's Status to `Accepted` and date.
5. If the answer affects a related document (e.g., schema change), update that doc.
6. If the answer is "Defer", change Status to `⚪ Deferred` and add a note about when to revisit.

If you reject a recommendation:
1. Status stays `🔴 Open`.
2. Add a Note: `REJECTED RECOMMENDATION (YYYY-MM-DD): rationale...`.
3. PM proposes new recommendation; cycle continues.
