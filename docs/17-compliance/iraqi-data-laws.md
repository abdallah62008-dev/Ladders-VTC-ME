# Iraq Data Laws

**Status:** Draft (stub)
**Owner:** Legal

Iraq's data protection regime is less formalized than KSA/Egypt. We default to higher of {KSA, EG} standards.

## Approach

- Apply same baseline data protection controls as KSA + EG.
- Document customer consent + opt-out per Iraqi customer.
- Cross-border transfers: maintain MENA-region hosting where possible.
